TAQUERÍA LA CHINITA — PÁGINA WEB

Cómo abrir el proyecto en Visual Studio Code

1. Descomprime el archivo ZIP.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta.
4. Elige la carpeta "Taqueria-La-Chinita".

Archivos principales

- index.html: estructura y contenido de la página.
- styles.css: colores, diseño y adaptación a celulares.
- script.js: menú móvil y funciones básicas.
- hero-tacos.jpg: imagen principal.

Cómo verla en tu computadora

Puedes abrir index.html directamente en el navegador. Para trabajar con una
vista que se actualice, instala en Visual Studio Code la extensión Live Server,
haz clic derecho sobre index.html y selecciona "Open with Live Server".

Nota: los botones de WhatsApp utilizan el número 221 580 22 39.

Pedidos a domicilio
- El cliente agrega productos, paquetes o especialidades y abre "Ver mi carrito".
- Puede cambiar cantidades, quitar productos y escribir nombre, dirección y notas.
- "Continuar en WhatsApp" prepara el mensaje al 221 580 22 39; el cliente debe enviarlo.
- El subtotal está en MXN y excluye envío y productos con precio por confirmar.
- El carrito se guarda en este navegador cuando localStorage está disponible.
- Nombre, dirección y notas no se guardan en localStorage.
- Para cambiar el destino de los pedidos, edita WHATSAPP_NUMBER en script.js.
- Los precios se toman del HTML; las opciones de kilogramo de especialidad usan $330 en script.js.
- Las imágenes están en assets/: logo-taqueria.png y hero-tacos.jpg.
- No requiere backend ni instalación de dependencias.
